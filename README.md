# Centro de Simulación Digital IPG – Escuela de Gestión, Negocios y Marítima

Sitio estático preparado para publicar mediante GitHub Pages, Netlify o un servidor web institucional.

## Estructura

- `index.html`: portada del portal.
- `wms/index.html`: IPG WMS Simulator V2 funcional.
- `comex/index.html`: página de módulo COMEX en desarrollo.
- `portsim/index.html`: página de módulo PORTSIM en desarrollo.
- `rrhh/index.html`: página de módulo PEOPLE en desarrollo.
- `finanzas/index.html`: página de módulo FIN-SIM en desarrollo.
- `marketing/index.html`: página de módulo MARKETING en desarrollo.

## Publicar en GitHub Pages

1. Crear un repositorio nuevo en GitHub, por ejemplo `ipg-simuladores`.
2. Subir **todo el contenido de esta carpeta**, respetando la estructura de subcarpetas.
3. En el repositorio ir a `Settings > Pages`.
4. En `Build and deployment`, seleccionar `Deploy from a branch`.
5. Elegir `main` y `/ (root)`.
6. Guardar.
7. GitHub entregará una URL similar a `https://usuario.github.io/ipg-simuladores/`.

## Uso en Moodle

- Publicar la URL del simulador como recurso/enlace.
- Entregar junto a ella el caso, instrucciones y rúbrica.
- En WMS V2, solicitar al estudiante su evidencia final PDF/CSV según la actividad.

## Recomendación institucional

Antes de uso masivo, realizar un piloto con una sección, verificar navegadores, instrucciones y forma de entrega de evidencias. El WMS V2 guarda datos en el navegador del usuario y no utiliza un servidor central.
