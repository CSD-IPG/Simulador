Guía rápida para comenzar

Antes de iniciar, revisa este flujo. Puedes suspender tu sesión y volver más tarde sin perder el avance.

  1. Completa tu identificación y código de actividad.
  2. Revisa el Panel y los indicadores iniciales.
  3. Recepciona al menos una orden de compra.
  4. Comprueba el inventario disponible.
  5. Ejecuta el flujo Picking → Packing → Despacho.
  6. Activa una contingencia y registra tu decisión.
  7. Consulta Evidencia para revisar tu bitácora y resultados.
  8. Al terminar, utiliza Finalizar y volver al portal.
Qué registra el sistema

Identificación, sección, actividad, tiempo efectivo, operaciones realizadas, avance, puntaje, errores, contingencias y respuestas registradas.

Si necesitas salir antes de terminar

Usa Guardar y volver al portal. El cronómetro se detiene y podrás continuar después desde la misma sesión.
